# auto-memory の相互参照記法

auto-memory ストア（`~/.claude/projects/<slug>/memory/`）では `[[wikilink]]` 記法を使わない。

- **メモリ間の相互参照** — `[name](name.md)` 形式
- **メモリ以外への参照**（skill 名・repo 内のファイル）— バッククォートのパス表記

**なぜ**: wikilink はプレーン Markdown として解決されず、リンク先が存在しなくてもリンク切れとして検出されない。標準のメモリ書き込み機能は wikilink を使う指示を内蔵しているため、意識しないと混入し続ける。

`[[...]]` を見つけたら、メモリ間参照は `[name](name.md)` へ、メモリ外参照はパス表記へ正規化する。

**適用範囲はメモリストアだけ**。リポジトリの `.learnings/` は逆に `[[slug]]` 記法を使うので、そちらへ持ち込まない。
